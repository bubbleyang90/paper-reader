## 纸页 Paper v0.1.1

### Markdown 文件关联
- Windows 安装版自动注册 .md、.markdown、.mdown 的“打开方式”和默认应用候选项，不覆盖已有默认程序，不改写 UserChoice。
- 要让双击始终使用 Paper：在“阅读设置 → 设置默认应用”中打开 Windows 设置，由你确认选择 Paper。
- 支持中文、空格路径、相对路径、冷启动及已运行窗口打开；重复打开会重新读取，较早慢读取不会覆盖最新文档。
- 卸载只清理仍属于本安装目录的注册项，保留其他应用与新安装实例的注册。

### 下载
- **安装版（推荐）**：Paper-v0.1.1-windows-x64-setup.exe；当前用户安装，支持简体中文/English，包含文件关联与卸载程序。
- **便携版**：Paper-v0.1.1-windows-x64.zip；完整解压后运行 Paper.exe，不注册文件关联。
- 两者均为 **Windows x64、未代码签名**，系统可能提示未知发布者。均需要 Microsoft Edge WebView2 Runtime；安装器在缺少 Runtime 时下载引导程序，需要联网。
- SHA256SUMS.txt 用于验证安装器与 ZIP 完整性。

### 验证与限制
本次发布流程通过 12 项 Windows Rust 测试、15 项 Edge 浏览器回归、rustfmt、版本校验、生产 NSIS 构建，以及真实 WebView2 冷/热启动和安装注册/卸载测试。
原生自动验收使用同源码但临时增加进程级 CDP 参数和隔离目录的测试安装包；该包不会上传。发布的生产产物在测试重建前单独保存，无 CDP 调试端口，也不修改系统调试策略。
真实 Explorer 默认应用选择及完整双击流程、旧发行版升级未自动覆盖；不是对生产二进制逐字节相同的原生 UI 验收。保留 v0.1.0，不覆盖旧版本。
